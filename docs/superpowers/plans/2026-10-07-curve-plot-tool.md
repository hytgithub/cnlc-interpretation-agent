# 独立曲线绘图工具实施计划

## 目标与依据

依据产品需求第二节“动态工作台”、目标概要“工作台联动”、详细技术方案5.2及11.2曲线契约，以及用户本轮要求补齐绘图工具。新增 `plot_curves`：独立绘制指定井段原始曲线或本会话已有结果曲线，聊天页面直接显示并下载图表。

## 约束与决策

- 保持专业工具独立调用、完整解释由 Skill 按十项专业步骤组织；系统提示词不加入阶段表或数据实现说明。
- 绘图绑定井、资料版本、MD深度和曲线；保留空值断线、单位及来源，深度向下增加。
- 不修改数据、参数和当前选择，不执行解释或重跑。历史结果绘图标明是否过期。
- SVG保存为独立文件，聊天仅传摘要和受控查询引用；HTTP读取检查用户、会话和Agent归属。沿用已有结果仓储记录图表，不引入独立存储系统。
- 复用当前聊天工具渲染器。原始数据与已有解释结果分别绘制；未提供的专业解释字段不猜测。
- 当前四项交互业务实现和目录仍在，注册入口与已确认清单不一致：补回入口并通过既有回归确认。
