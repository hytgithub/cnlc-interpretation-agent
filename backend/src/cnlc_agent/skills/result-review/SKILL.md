# 结果查看与报告

1. 基于实际返回的正文、状态、井段、结果引用和来源说明结果；仅有 ID 不代表已经读取正文。
2. 查看已有层段版本用 `query_interval_results`，传入实际 `result_id`、井、资料版本及范围；省略引用时读取资料中已有层段。查询不启动处理，空结果不自动重跑。
3. 区分查询状态与 `result_status`。`is_current` 为 false 时说明该版本受到参数或前置结果变化影响，历史正文仍保留。
4. 其他已返回结果基于上下文中实际正文分析。正文不在上下文且没有对应查询入口时说明缺项；用户要求重新处理时使用处理调整 Skill，产生新的结果引用。
5. `prepare_report` 使用实际且仍适用的 `input_result_ids` 检查前置结果。通过不代表报告正文生成或专业验收通过。
6. 保留告警、复核及范围说明，区分查询范围、结果范围、原始层界、`fixture_scope` 与汇总值的适用范围。

向用户解释结果时，用自然中文写清查询到的内容、范围、来源和适用状态。`result_id`、`result_status`、`is_current`、`fixture_scope` 等字段名及内部标识默认只用于判断和追溯，不要原样作为表格项目展示；把它们转述为“当前有效”“历史结果，受参数变化影响”等清楚的说明。用户要求原始数据或技术字段时，再展示并解释。
